# Pik2Video

**Pik2Video** — приложение для записи экрана и создания видео с гибкими настройками.

Поддерживает два режима:
- **Запись видео** — непрерывная запись экрана в MP4 с выбором FPS, качества и таймера.
- **Screen-захват** — серийная съёмка кадров с заданной частотой (кадры в минуту) с последующей сборкой в видео (GIF, MP4, MKV, AVI, MOV).

## Возможности
- Выбор области записи (перетаскиванием или через пресеты)
- Настройка качества, FPS, таймера автоматической остановки
- Поддержка FFmpeg (для кодирования и сборки)
- Сохранение настроек между сессиями
- Готов к сборке в `.app` (macOS) и `.exe` (Windows) через PyInstaller

## Требования
- macOS (тестировалось на 11+), но код по идеи должен быть кроссплатформенным
- Python 3.8 или выше
- [FFmpeg](https://ffmpeg.org/) (установленный в системе и доступный в `PATH`)
- [Rye](https://rye.astral.sh/) (менеджер зависимостей)

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Pik2Video/Pik2video.git
cd Pik2Video
```

2. Установите зависимости через Rye:
```bash
rye sync
```

3. Убедитесь, что FFmpeg установлен:
```bash
ffmpeg -version
```
Если нет — установите через `brew install ffmpeg` (macOS).

## Сборка приложения

Для сборки в `.app` (macOS) используется скрипт `build.sh`:

```bash
chmod +x build.sh   # только при первом запуске
./build.sh
```

После сборки готовое приложение появится в папке `dist/Pik2Video.app`. Перенесите его в `Программы` или запустите двойным кликом.

### Альтернативная сборка (без перегенерации иконок)
```bash
rye run pyinstaller --onedir --windowed --name="Pik2Video" --icon="resources/icons/app_icon.icns" --add-data "resources/icons:resources/icons" --hidden-import PySide6.QtCore --hidden-import PySide6.QtGui --hidden-import PySide6.QtWidgets src/main.py
```

## Структура проекта

```
Pik2Video/
├── src/                     # Исходный код приложения
│   ├── main.py              # Точка входа
│   └── pik2video/           # Основной пакет
│       ├── application/     # Логика, контроллер, состояния
│       ├── core/            # Захват кадров, FFmpeg, сборка видео
│       ├── gui/             # Интерфейс (Qt)
│       ├── infrastructure/  # Вспомогательные сервисы (FFmpeg, логирование)
│       ├── locale/          # Файлы переводов (ru/en)
│       └── storage/         # Временное хранилище сессий
├── resources/               # Иконки, фоны, медиа
├── scripts/                 # Генерация иконок, экспорт кода
├── logs/                    # Логи (не в репозитории)
├── export/                  # Экспорт кода для ИИ (не в репозитории)
├── build.sh                 # Скрипт сборки
├── pyproject.toml           # Конфигурация Rye
└── README.md                # Этот файл
```

## Запуск в режиме разработки

```bash
rye run python src/main.py
```

Для отладки с логированием:
```bash
rye run python src/main.py --debug
```
